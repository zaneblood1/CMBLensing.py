The data and figures in these folders is maintained by hand. New data should be dropped into the correct folder and documented with an experimental_details.md file explaining the experimental details about how it was generated. 

```/map_joint_comparison``` contains plots and tables comparing the run time and accuracy of the ```map_joint``` algorithm between the CMBLensing.jl and CMBLensing.py implementations along with the .txt and .npz files needed to regenerate these figures.

```/lcdm_sampling``` contains the learned distributions, autocorrelation plots, data, etc. from runs of the ```sample_joint``` method in ```sample_lcdm.py```.
