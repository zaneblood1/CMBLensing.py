    Fisher Forecast¶

    A Gaussian Fisher forecast of the sampler's posterior widths, for temperature (I), polarization (P) or joint (IP) data, from per-mode covariance blocks on the sampler's own rfft grid:

    \[ F_{ij} = \frac{1}{2} \sum_\text{blocks} \sum_k w_k \, \mathrm{Tr}\!\left[ C_k^{-1} \frac{\partial C_k}{\partial \theta_i}\, C_k^{-1} \frac{\partial C_k}{\partial \theta_j} \right], \]

    with \(w_k\) the rfft mode weights (2 per bulk mode, 1 on the self-conjugate columns). For a single-number block the trace is \(\partial_i \ln C_k \, \partial_j \ln C_k\).

    Analyzing Chain Data compares the forecast with a set of chains.

    The blocks¶

    pol Field blocks Phi block
    I \(C_{TT} + N_{TT}\) \(C_\phi + N_\phi\)
    P \(C_{EE} + N_{EE}\); \(C_{BB} + N_{BB}\) same
    IP \(\begin{pmatrix} C_{TT} + N_{TT} & C_{TE} \\ C_{TE} & C_{EE} + N_{EE} \end{pmatrix}\); \(C_{BB} + N_{BB}\) same
    • The field blocks are always measured. Their signal at \(\theta_0\) and \(\theta_0 \pm h_i\) is the empirical delensed covariance given as delensed_covariance, measured at the same box, noise level and pol. The finite-difference steps \(h_i\) come from that file. Without the file the forecast is an error: there is no analytic delensing.
    • The noise is analytic and independent of the cosmology, with \(N_{EE} = N_{BB} = 2 N_{TT}\).
    • The phi block uses \(C_\phi(\theta)\) from direct CAMB calls and an \(N_\phi\) held at \(\theta_0\).

    Choosing N_phi¶

    Option N_phi
    default the quadratic-estimate \(N^{(0)}\) of the box, built like load_sim's (the TT estimator for I, the EB estimator for P and IP), with the unlensed spectra in both its response and its filter
    qe_filter = "lensed" (--qe_filter lensed) the same, with the lensed spectra in the filter; the response stays unlensed
    phi_noise = <npz> (--phi_noise <npz>) the nphi of a merged map_joint_phi_noise.npz or sampler_phi_noise.npz; unmeasured (NaN) modes carry no phi information

    Build the delensed covariance's Wiener filter from the same N_phi the forecast uses; nothing checks it.

    Command line¶

    python -m cmb_lensing.fisher_forecast --noise 5 --delensed_covariance delensed_covariance.npz
python -m cmb_lensing.fisher_forecast --noise 5 --delensed_covariance delensed_covariance.npz --qe_filter lensed
python -m cmb_lensing.fisher_forecast --noise 5 --delensed_covariance delensed_covariance.npz --phi_noise map_joint_phi_noise.npz
python -m cmb_lensing.fisher_forecast --noise 5 --pol IP --delensed_covariance delensed_covariance_IP.npz
python -m cmb_lensing.fisher_forecast --noise 5 --pol IP --delensed_covariance delensed_covariance_IP.npz --no_bb

    Other flags: --nside, --theta_pix, --l_knee, --beam_fwhm, --params (default logA omch2 theta_MC_100), --camb_lmax (default 4000, the support of the simulations).

    Outputs go to cmb_lensing/fisher_output/ as fisher_matrix, covariance_matrix, correlation_matrix (PNG) and fisher (npz), each tagged _<pol>_<nphi>_<noise>_uk, e.g. fisher_I_qe_unlensed_5_uk.npz. Parameters are in the package's standard order: theta_MC_100, logA, ns, ombh2, omch2.

    What the forecast leaves out¶

    • The blocks are added as independent. The residual lensing left in the delensed field tracks \(C_\phi(\theta)\), so the field blocks count some of the lensing information the phi block already has.
    • The delensed BB is pure residual lensing at \(r = 0\). Its modes are neither Gaussian nor independent, so counting them as such is optimistic; include_bb = False (--no_bb) leaves the BB block out and shows how much of a P or IP forecast rests on it.
    • The correlations between the fields and phi are ignored.
    • For IP the \(N^{(0)}\) is the EB estimator's, as in the sampler; a combined temperature and polarization estimator would be lower.
    • Parameters that are not sampled (not in --params) are held fixed, not marginalized over.

    def forecast(nside, theta_pix, noise_level, is_sampled, param_ground, delensed_covariance,
             pol = DEFAULT_POL, qe_filter = DEFAULT_QE_FILTER, phi_noise = None,
             include_bb = True, l_knee = 0, beam_fwhm = 0, l_cutoff = DEFAULT_ELL_CUTOFF,
             camb_lmax = CAMB_LMAX):
    """Gaussian Fisher matrix for the sampled LCDM parameters on an nside x nside box.

    Args:
        nside:        pixels per side of the box
        theta_pix:    pixel width in arcmin
        noise_level:  noise in uK-arcmin in temperature; the polarization noise is sqrt(2)
                      higher
        is_sampled:   {param_name: bool}; False parameters are held FIXED
        param_ground: {param_name: float} fiducial point, all five
        delensed_covariance: a merged delensed_covariance.npz measured at this box, noise
                      level and `pol` (required): the field blocks' delensed signal at
                      theta_0 and theta_0 +/- h, and the steps h
        pol:          "I" (temperature), "P" (polarization) or "IP" (both): the data
        qe_filter:    "unlensed" (default) or "lensed": the spectra in the filter of the
                      quadratic-estimate N0 used as the phi noise. Its response always uses
                      the unlensed spectra. The estimator is load_sim's: TT for "I", EB for
                      "P" and "IP"
        phi_noise:    a merged map_joint_phi_noise.npz / sampler_phi_noise.npz whose `nphi`
                      replaces the QE N0
        include_bb:   for "P" / "IP", whether the delensed BB block is counted
        l_knee:       1/f knee of the noise (0 = white, as every sampler entry point)
        beam_fwhm:    beam FWHM
        camb_lmax:    how far CAMB is run (default CAMB_LMAX, the simulations' support)

    Returns:
        fisher (numpy.ndarray): the n_sampled x n_sampled Fisher matrix, rows and columns
            in constants.PARAM_ORDER.
        names (list): the sampled parameter names, in constants.PARAM_ORDER.

    Raises:
        ValueError: if delensed_covariance is None.
    """
    names, steps, blocks_fid, blocks_plus, blocks_minus = covariance_stencil(
        nside, theta_pix, noise_level, is_sampled, param_ground, delensed_covariance,
        pol = pol, qe_filter = qe_filter, phi_noise = phi_noise, include_bb = include_bb,
        l_knee = l_knee, beam_fwhm = beam_fwhm, l_cutoff = l_cutoff, camb_lmax = camb_lmax)
    return fisher_from_blocks(blocks_fid, blocks_plus, blocks_minus, steps, nside), names
